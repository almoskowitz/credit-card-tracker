# Installation & Setup Guide

## 📥 Download

### From GitHub
```bash
git clone https://github.com/yourusername/credit-card-tracker.git
cd credit-card-tracker
```

### Direct Download
1. Go to the [Releases](https://github.com/yourusername/credit-card-tracker/releases) page
2. Download the latest `credit-card-tracker.html` file
3. Save anywhere on your computer

## 🚀 Running the Application

### Desktop (All Platforms)

**Windows:**
- Double-click `credit-card-tracker.html`
- OR: Right-click → Open with → Chrome/Firefox/Edge

**macOS:**
```bash
open credit-card-tracker.html
```

**Linux:**
```bash
xdg-open credit-card-tracker.html
# OR
firefox credit-card-tracker.html
```

### Mobile

**iOS (iPhone/iPad):**
1. Download file to Files app
2. Tap the file to open in Safari

**Android:**
1. Download to device
2. Open with Chrome/Firefox

## 💾 Data Backup

Your data is stored in browser local storage. To back up:

### Manual Backup
1. Open browser developer tools (F12)
2. Go to Application → Local Storage
3. Copy the values for:
   - `my-cards`
   - `profiles`
   - `used-benefits`
   - `card-database`
   - `annual-spending`

### Automatic Export (Coming Soon)
Future version will include Export/Import functionality.

## 🔄 Updating

### If Downloaded Directly
1. Download new version
2. Replace old file
3. Open in browser - your data persists!

### If Using Git
```bash
git pull origin main
```

Your browser storage is separate from the file, so updates won't affect your data.

## 🧹 Uninstalling

### Remove Application
Just delete the HTML file!

### Clear Data
**Chrome:**
1. F12 → Application → Local Storage
2. Right-click → Clear

**Firefox:**
1. F12 → Storage → Local Storage
2. Right-click → Delete All

**Safari:**
1. Develop → Show Web Inspector → Storage
2. Delete items

## 🔒 Privacy & Security

- **100% Local** - All data stays in your browser
- **No Server** - Nothing sent over the network
- **No Tracking** - No analytics or cookies
- **No Account** - No login required

## 🐛 Troubleshooting

### File Won't Open
- Make sure you have a modern browser installed
- Try right-click → Open With → [Browser Name]
- Check file wasn't corrupted during download

### Data Not Saving
- Enable cookies/local storage in browser settings
- Not in Incognito/Private mode
- Have at least 10MB storage available

### Looks Broken
- Hard refresh: Ctrl+Shift+R (Cmd+Shift+R on Mac)
- Clear browser cache
- Try different browser
