# Quick Start Guide

Get up and running with Credit Card Rewards Tracker in 5 minutes!

## ⚡ Super Fast Start

1. Download `credit-card-tracker.html`
2. Double-click to open in browser
3. Done! Start tracking immediately.

## 📱 First Steps

### Step 1: Create Your Profile (30 seconds)
```
1. Click "Manage Profiles" button
2. Type your name (e.g., "Andrew")
3. Click "Add Profile"
4. Click "Close"
```

### Step 2: Add Your First Card (30 seconds)
```
1. Click "+ Add Card" button
2. Select your profile from dropdown
3. Click on a card (e.g., "Amex Platinum")
4. Card appears in your dashboard!
```

### Step 3: Track a Benefit (10 seconds)
```
1. Click on your card to expand it
2. Click any benefit tile to mark as used
3. Watch the percentage update! ✨
```

## 🎯 Common Tasks

### Add Multiple Cards
- Repeat Step 2 for each card
- Same card can be added multiple times for different profiles

### Mark Benefits as Used
- Click the card header to expand
- Click green tiles = unused benefits
- Tiles with ✓ = already used

### View Wallet Recommendations
- Click "Optimize" tab
- Enter your annual spending by category
- See which cards to use for each purchase type
- Get 3/5/7-card wallet suggestions

### Create a Second Profile
- Great for tracking partner/spouse cards separately
- Each profile can have the same cards
- Benefits tracked independently

## 💡 Pro Tips

**Tip 1: Monthly Benefits Reset**
Benefits automatically reset each period. February benefits only show in February!

**Tip 2: Recovery Percentage**
The donut chart shows how much of your annual fee you've recovered from benefits.

**Tip 3: Best Card Feature**
The Optimize tab shows which card earns the most points for each category based on your active cards.

**Tip 4: Data Persists**
Everything saves automatically. Close and reopen anytime!

## 🐛 Troubleshooting

**Q: I don't see any cards**
A: Make sure you created a profile first, then add cards to that profile

**Q: Benefits aren't showing**
A: Only current period benefits show. If it's February, you'll only see February/Q1/H1/Annual benefits

**Q: Numbers aren't updating**
A: Make sure you're clicking the benefit tiles, not just looking at them

**Q: Want to start over?**
A: Clear browser storage or use incognito mode for a fresh start
